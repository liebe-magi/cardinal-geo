# Noto Sans JP

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp

`NotoSansJP.ttf` is a static weight-500 instance of `NotoSansJP[wght].ttf`,
retrieved on 2026-10-04 and instantiated with FontTools (`varLib.instancer`, `wght=500`).
It is bundled so the server image renderer needs no runtime font download or system fonts.
See `OFL.txt` for the SIL Open Font License 1.1 and copyright attribution.
