# 結果データの移行

## 出題方向の保存（#23）

`20261004_answer_presentation.sql` を先に適用してからクライアントを切り替える。
`schema.sql` は新規環境の参照用で、本番へ直接適用しない。
この作業では本番DBへの適用は実施していない。

問題ペアの正規化順とは別に、回答のコミットメントへ提示したTarget・Origin・正解を保存する。
旧クライアントは追加列をNULLのまま書ける。旧履歴は提示順不明として、
正解方角・回答との比較・Origin/Targetの地図を表示しない。正誤から推定しない。
旧クライアントへ戻す際はクライアントだけ戻し、追加列は残す。
列の削除や過去回答のバックフィルは行わない。
